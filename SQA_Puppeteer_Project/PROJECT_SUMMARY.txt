================================================================
LESSONS LEARNED
================================================================

1. Puppeteer 24.40.0 Major Changes
   - Completely removed XPath support (not just deprecated)
   - Modern DOM API is now the standard for element selection
   - Promise-based sleeps replace deprecated timeout methods

2. Page Interaction Strategy
   - page.evaluate() is the universal approach
   - Can return data from page context
   - Supports all DOM operations inside evaluate()

3. Test Status Flexibility
   - INFO status useful for workflow prerequisites
   - Not all unmet assertions indicate failures
   - Document expected page states clearly

4. File Upload in Automation
   - Puppeteer supports file upload via uploadFile()
   - Requires actual file path
   - Works even in production headless environments

5. Icon-Based UI Elements
   - Modern web apps use icon fonts (Material Icons, FontAwesome)
   - Text-based selectors won't find icon-only buttons
   - Use aria-label, title, or data-* attributes instead
